# CampusConnect — Java Course Registration System

A command-line university registration system that helps students find courses and build a conflict-free timetable.

## Features
- Browse and search available courses
- Enroll in courses with capacity validation
- Prevent duplicate registrations
- Detect timetable conflicts
- Display a student's current schedule
- Demonstrates Java records, collections, streams, validation, and menus

## Run locally

```bash
cd src
javac Course.java CourseRegistrationApp.java
java CourseRegistrationApp
```

## Technologies
Java 17+, Java Collections, Streams, Records
