# OrbitBoard — Project Management Kanban Board

A visual project workspace for organising delivery work across Backlog, In Progress, Review, and Completed stages.

## Features
- Drag-and-drop task workflow
- Owners, priorities, due dates, and task counts
- Progress dashboard metrics
- Create tasks from a modal form
- Browser persistence with `localStorage`

## Run locally
Open `index.html` or use VS Code Live Server.

## Technologies
HTML, CSS, JavaScript, Bootstrap 5, Web Storage API
