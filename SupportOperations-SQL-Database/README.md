# Support Operations SQL Database

A SQL Server database design for an internal IT support operation. The project models departments, agents, customers, tickets, comments, relationships, constraints, indexes, seed data, and reporting views.

## What it demonstrates
- Relational schema design and normalised tables
- Primary keys, foreign keys, unique constraints, and check constraints
- One-to-many relationships and cascade deletion
- Indexes for common ticket queries
- A reusable workload view
- Reporting queries for priority, workload, resolution time, and department demand

## Run locally
Open `schema.sql`, `seed.sql`, and `reports.sql` in SQL Server Management Studio or Azure Data Studio and execute them in that order.

## Technologies
Microsoft SQL Server, T-SQL, relational database design
