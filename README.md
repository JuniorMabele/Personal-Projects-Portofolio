# DeskFlow — IT Helpdesk Ticketing System

DeskFlow is a responsive internal IT support dashboard for managing service requests. It demonstrates practical business workflow design without requiring a backend or database: records persist in the browser with `localStorage`.

## Features
- Create, edit, delete, search, filter, and sort support tickets
- Track Open, In Progress, and Resolved workflows
- Priority levels, assignees, departments, and dashboard metrics
- Responsive Bootstrap interface
- Seeded sample tickets for an immediate demo

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Technologies
HTML, CSS, JavaScript, Bootstrap 5, Web Storage API
