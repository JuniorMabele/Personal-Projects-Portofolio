# CareerGrid — Job Application Tracker

A personal opportunity pipeline that helps job seekers track applications, interviews, recruiter contacts, and follow-up dates in one place.

## Features
- Track company, role, location, stage, contact, and follow-up date
- Move applications through a configurable pipeline
- Search and filter opportunities
- Dashboard metrics for active applications, interviews, and offers
- Browser persistence with `localStorage`

## Run locally
Open `index.html` or use VS Code Live Server.

## Technologies
HTML, CSS, JavaScript, Bootstrap 5, Web Storage API
