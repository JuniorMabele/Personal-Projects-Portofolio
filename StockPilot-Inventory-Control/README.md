# StockPilot — Inventory & Stock Control

A browser-based inventory control dashboard for small businesses. It highlights low-stock products and inventory value so staff can make better reorder decisions.

## Features
- Product catalogue with SKU, category, price, quantity, and reorder levels
- Low-stock and out-of-stock alerts
- Inventory valuation dashboard
- Search and category/stock filtering
- Quick stock adjustments
- Browser persistence with `localStorage`

## Run locally
Open `index.html` in a browser or use VS Code Live Server.

## Technologies
HTML, CSS, JavaScript, Bootstrap 5, Web Storage API
