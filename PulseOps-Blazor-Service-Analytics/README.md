# PulseOps — C# Blazor Service Analytics Dashboard

A Blazor WebAssembly dashboard for monitoring internal service performance. It uses in-memory sample data so it can be demonstrated without a database.

## Features
- Reusable Razor components and layouts
- Request queue metrics and category performance bars
- Request filtering and status visibility
- Form-style interaction for logging a new request
- Responsive custom dashboard design

## Run locally
Install the .NET 8 SDK, open this folder in a terminal, and run:

```bash
dotnet run
```

## Technologies
C#, .NET 8, Blazor WebAssembly, Razor, CSS
